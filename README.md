从**对偶问题**出发，把硬间隔/软间隔 SVM 的每个环节都做成可暴力对拍的**精确**算法，零依赖单文件 HTML。

核心卖点不是"画条分界线"，而是这三件事：

1. **SMO 的二变量子问题用解析解**（`α_j* = α_j + y_j(E_i − E_j)/η`，再钳到 `[L,H]`），而不是数值搜索；
   解析解与一维黄金分割搜索、一阶最优性条件三方对拍。
2. **两条完全独立的算法**解同一个对偶问题：SMO（工作集 + 解析子问题）与 PGA（投影梯度上升 + FISTA 加速），
   两者对偶目标一致到 1e-13。
3. **2D 硬间隔有精确最优性证书**：`f(θ) = min_P w·x − max_N w·x` 的全局极大点必落在
   「某对点差向量的平行/垂直方向」上，于是 O(n²) 候选方向全枚举就是精确最大间隔 ——
   SMO 的 `2/‖w‖` 与之吻合到 1e-13。**不依赖任何网格分辨率假设。**

```
对偶：max_α Σαᵢ − ½ Σᵢⱼ αᵢαⱼyᵢyⱼK(xᵢ,xⱼ)   s.t.  0 ≤ αᵢ ≤ C,  Σᵢ αᵢyᵢ = 0
决策：f(x) = Σᵢ αᵢyᵢK(xᵢ,x) + b        KKT：αᵢ=0 ⇒ y·f ≥ 1；0<αᵢ<C ⇒ y·f = 1；αᵢ=C ⇒ y·f ≤ 1
```

## 打开方式

直接双击 `index.html`。无构建、无网络、无依赖。

界面：数据集（separable / overlap / xor / moons / circles）、样本数、标签噪声、
核（linear / RBF / 多项式）、C、γ、d 三个滑块，支持向量用橙圈标出、界内（`α=C`）点半透明，
右侧画决策边界 + 间隔带 + `f(x)` 等值线、对偶目标收敛曲线、`α` 分布条形图，8 条不变量自检。

## 探针里几条值得单独看的实测

- **`b` 的可行区间 vs SMO 给的 `b`**：无自由 SV 时 `b` 由区间的中点定，有自由 SV 时由自由点的一致解定。
  实测 5 个场景的自由 SV 隐含 `b` 跨度都在 **1e-9**（正是 SMO 的 tol 量级），说明它们确实是同一个超平面。
- **为什么 `α` 的分类必须带容差**：`overlap/moons` 上 `α = 5.55e-17` 的浮点残渣，
  若用「精确 `α==0`」判定就会被当成**自由 SV**，要求 `y·f = 1`，于是报出 4.16e-2 的**假 KKT 违反**
  （同一解带容差判定只有 4.1e-13）。同时 `α` 会停在 `C−1e-12`，被当成自由会污染 `b` 的求解。
- **arginmax 只能精确到 √(2ε/η)**：一维子问题的目标求值噪声 `ε ≈ 1e-15`、曲率 `η`，
  所以「解析解与搜索解的 argmax 逐位吻合」是**物理上做不到**的断言，
  该断言的是「目标值一致」与「一阶条件符号正确」。实测目标差 7e-15、`D′(解) ≈ 0` 或符号正确。
- **`overlap/s6002` 其实是线性可分的**：26 点、标签噪声 0.25，精确最大间隔 0.4227 > 0。
  20 万 / 50 万方向网格都只给 **0.0435**（低估 89.7%，且加密完全不改善）——
  可行方向锥太窄，网格采不到。用网格判可行性会把可分数据误判成不可分。
- **只扫「过原点」的方向会系统性低估间隔**：不优化 `b` 时得到 1.3982，真值 1.4219（低 1.7%），
  且**加密不收敛**。这是实现这个证书最容易踩的坑。

## 常见坑（本项目踩过的）

1. **SMO 的工作集选择判据不是 `−yᵢEᵢ`**。因为 `y_i G_i = b − E_i`、`b` 在判据里约掉，
   最大违反对是 `i = argmin_{I_up} E`、`j = argmax_{I_low} E`。写反了会在第 1 步就"误判收敛"。
2. **工作集卡在边界时要回退**：最大违反对的子问题可能被 clamp 回原点（`η→0`）。
   标准做法是"第二选择启发式 + 全扫描",否则 `moons` 这类数据 10 步就退出、KKT 停在 0.29。
3. **`C` 极大 + 不可分数据 = 对偶病态**（`α ∈ [0,1e5]`），SMO 4 万轮也收敛不了。
   这不是实现 bug，是配置错 —— 硬间隔证书本来就只对可分数据有定义。
4. **多项式核只能用相对/后向误差断言**：`d=5` 时 `(x·z+1)⁵` 量级可达 1e7，
   绝对误差 4.7e-10 对应后向误差 7.75e-16 —— 是浮点本身的极限，不是实现错。
5. **`argmax` 的定位精度受求值噪声限制**（见上），断言要写成 `Δα²·η` 这样对噪声不敏感的形式。
6. **近可分数据的可行性不能用网格判**（见上），必须用精确枚举。
